# 🚀 API de Usuários (FastAPI)

Projeto de API REST desenvolvido com Python utilizando FastAPI.

## 🔧 Funcionalidades

- Cadastro de usuários
- Listagem de usuários
- Busca por email
- Atualização de dados
- Remoção de usuários
- Validação de dados

## 🛠️ Tecnologias

- Python
- FastAPI
- Pydantic

## ▶️ Como executar

```bash
pip install fastapi uvicorn email-validator
uvicorn main:app --reload
